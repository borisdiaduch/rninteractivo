# rninteractivo

Infografías interactivas de Diario Río Negro, publicadas con GitHub Pages.

- Índice: https://borisdiaduch.github.io/rninteractivo/
- Cada proyecto es un `.html` autocontenido en [`infografia/`](infografia/), con su captura en [`preview/`](preview/).

## Sumar un proyecto

1. Subir el `.html` a `infografia/` y una captura de 800×600 a `preview/`.
2. En `index.html`, copiar un `<li>` arriba de todo (los más recientes primero) con el link, la captura, el título y el link de la nota en rionegro.com.ar.
